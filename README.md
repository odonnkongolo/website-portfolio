# Odon Nkongolo - Personal Portfolio

Welcome to my personal portfolio website! This project is a modern, premium web application built with React, Vite, and Vanilla CSS. It features a high-contrast dark theme, smooth scrolling, dynamic custom cursors, and custom background visuals tailored to showcase my experience as an SRE & Platform Engineer.

## Technologies Used
- **React**: For building the component-based UI.
- **Vite**: For blazing fast local development and building.
- **Lenis**: For buttery smooth scrolling physics.
- **Vanilla CSS**: For custom, high-performance styling and animations.

## How to Run the Website Locally

You have a few options to run this website on your computer:

### Option 1: 1-Click Run (Mac)
If you are on a Mac, you can simply double-click the `run.command` file located in this folder. 
This will automatically open a terminal, install any required dependencies, and launch the website in your browser.

### Option 2: Using the Terminal
If you prefer using the terminal (or are on another operating system), follow these steps:

1. Open your terminal and navigate to this folder (`website-portfolio`).
2. Run the following command to install dependencies:
   ```bash
   npm install
   ```
3. Run the following command to start the development server:
   ```bash
   npm run dev
   ```
4. Open your web browser and go to `http://localhost:5173` to view the website.
